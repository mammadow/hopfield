Hopfild şəbəkəsi (qraf)

Neyronun altında: y – yaxşı tillərin çəkiləri cəmi, p – pis tillərin. Neyron razıdır ⇔ y ≥ p. Neyrona klikləsəniz, onu əl ilə çevirib yeni başlanğıc konfiqurasiya yaradırsınız.

    Məsələnin qoyuluşu

    • Hopfild şəbəkəsi yönləndirilməmiş G = (V, E) qrafıdır. Hər təpə bir neyrondur, hər tilin tam ədəd çəkisi we var.
    • Konfiqurasiya S hər neyrona bir vəziyyət verir: su ∈ {−1, +1}.
    • e = (u, v) tili yaxşıdır, əgər we·su·sv < 0. Yəni we < 0 olanda u və v eyni vəziyyətdə olmaq istəyir, we > 0 olanda isə fərqli.
    • u neyronu razıdır, əgər ona bitişik yaxşı tillərin çəkiləri cəmi pis tillərinkindən kiçik deyilsə: Σv wuv·su·sv ≤ 0.
    • Bütün neyronlar razıdırsa, konfiqurasiya stabildir. Sual: stabil konfiqurasiya həmişə varmı və onu necə tapmaq olar?

    Lokal axtarış: State-Flipping alqoritmi

    Axtarış fəzası 2n konfiqurasiyadır. Bir konfiqurasiyanın qonşuları tək bir neyronu çevirməklə alınanlardır (Hamming məsafəsi 1). Alqoritm hər addımda «pis» vəziyyətdə olan bir neyronu düzəldir.

    Teorem (dayanma)

    State-Flipping alqoritmi ən çox W = Σe |we| iterasiyadan sonra dayanır və stabil konfiqurasiya qaytarır. Nəticə: hər Hopfild şəbəkəsinin ən azı bir stabil konfiqurasiyası var.

    İsbat (potensial funksiya ilə). Φ(S) = Σe yaxşı |we| götürək. Aydındır ki, 0 ≤ Φ(S) ≤ W. Razı olmayan u neyronunu çevirək. u-ya bitişik yaxşı tillərin cəmi gu, pis tillərinki bu olsun. Çevirmədən sonra u-ya bitişik yaxşı tillər pis olur, pis tillər isə yaxşı. Qalan tillər dəyişmir. Ona görə:

    Φ(S′) = Φ(S) − gu + bu.

    u razı olmadığı üçün bu > gu. Çəkilər tam ədəd olduğundan bu ≥ gu + 1, deməli Φ(S′) ≥ Φ(S) + 1. Φ hər addımda ən azı 1 artır və W-dən böyük ola bilmir. Buna görə alqoritm ən çox W addım atır. Alqoritm yalnız razı olmayan neyron qalmayanda dayanır, yəni nəticə stabildir. ∎

    Enerji ilə əlaqə: E(S) = Σe wesusv olarsa, Φ = (W − E)/2. Yəni Φ-nin artması Hopfild enerjisinin azalması deməkdir. Stabil konfiqurasiyalar enerjinin lokal minimumlarıdır.

    Max-Cut ilə əlaqə (KT §12.4)

    Bütün çəkilər müsbət olsun. Onda yaxşı til uc nöqtələri fərqli vəziyyətdə olan tildir, yəni (A = {s=+1}, B = {s=−1}) kəsiyindən keçən tildir. Bu halda Φ kəsiyin çəkisidir və State-Flipping alqoritmi Max-Cut üçün lokal axtarışa çevrilir. Teorem: istənilən lokal optimal kəsik üçün w(A, B) ≥ ½·W ≥ ½·OPT, yəni lokal axtarış 2-approksimasiya verir.

    Tətbiq: assosiativ yaddaş

    P sayda ξ1, …, ξP obrazı Hebb qaydası ilə yadda saxlanılır: wij = −Σp ξpi ξpj. KT konvensiyasında mənfi çəki «eyni vəziyyət» deməkdir. Obrazlar bir-birinə çox oxşamırsa, onların hər biri stabil konfiqurasiya olur. Küylü şəkildən başlanan lokal axtarış Φ-ni artıra-artıra ən yaxın stabil konfiqurasiyaya, adətən orijinal obraza gəlib çatır. Xatırlama prosesi elə lokal axtarışın özüdür.

    Python kodu (hopfield.py)

    def state_flipping(net, s0, strategy="random", rng=None, max_steps=None):
    """
    Kleinberg–Tardos State-Flipping alqoritmi.

    Səmərəli versiya: hər neyron üçün h_u = Σ w_uv s_v saxlanılır və
    razı olmayan neyronlar çoxluğu (U) yenilənir. Beləliklə bir çevirmə
    O(deg(u)) vaxt aparır (seçim strategiyasından asılı olaraq + O(|U|)).

    Qaytarır: Result (stabil konfiqurasiya, addımlar, Φ tarixçəsi).
    """
    if strategy not in STRATEGIES:
        raise ValueError(f"Naməlum strategiya: {strategy}")
    rng = rng or random.Random()
    s = list(s0)
    h = [net.local_field(s, u) for u in range(net.n)]
    unsatisfied = {u for u in range(net.n) if s[u] * h[u] > 0}
    phi = net.potential(s)
    result = Result(state=s, phi_history=[phi])

    while unsatisfied:                                 # stabil deyilsə...
        if max_steps is not None and result.flips >= max_steps:
            break

        # 1) Razı olmayan bir u neyronunu seç
        if strategy == "first":
            u = min(unsatisfied)
        elif strategy == "random":
            u = rng.choice(sorted(unsatisfied))
        else:  # greedy
            u = max(unsatisfied, key=lambda x: (s[x] * h[x], -x))

        # s_u · h_u = b_u − g_u  >  0  (razı deyil). Çəkilər tam olduğuna görə ≥ 1.
        gain = s[u] * h[u]
        g = (sum(abs(w) for _, w in net.neighbors[u]) - gain) // 2
        b = g + gain

        # 2) Vəziyyəti çevir: yaxşı tillər pis olur, pis tillər yaxşı.
        s[u] = -s[u]
        phi_new = phi - g + b                          # = phi + gain ≥ phi + 1
        assert phi_new >= phi + 1, "Teorem pozuldu: Φ ən azı 1 artmalıdır"

        # 3) Qonşuların sahəsini və razılıq vəziyyətini yenilə
        unsatisfied.discard(u)                         # indi s_u·h_u = −gain < 0
        for v, w in net.neighbors[u]:
            h[v] += 2 * w * s[u]
            if s[v] * h[v] > 0:
                unsatisfied.add(v)
            else:
                unsatisfied.discard(v)

        result.steps.append(Step(u, g, b, phi, phi_new))
        result.phi_history.append(phi_new)
        phi = phi_new

    assert result.flips <= net.W, "Teorem pozuldu: addım sayı W-dən çox ola bilməz"
    return result
